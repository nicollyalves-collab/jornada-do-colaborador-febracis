# Febracis Ascent

# JORNADA DO COLABORADOR | HOLDING FEBRACIS

Você é um UX/UI Designer Sênior, Product Designer e Desenvolvedor Front-End especialista em aplicações corporativas.

Sua missão é criar uma aplicação web moderna chamada **Jornada do Colaborador**, destinada ao onboarding de novos colaboradores do setor Pedagógico da Holding Febracis.

## OBJETIVO

Criar uma plataforma semelhante a uma Universidade Corporativa.

O usuário deve conseguir conhecer a empresa, entender sua cultura, conhecer o time, acessar ferramentas, aprender os processos e consultar documentos importantes.

A aplicação deverá ser escalável, permitindo adicionar novos módulos futuramente.

Não crie apenas um site institucional.

Crie uma EXPERIÊNCIA.
